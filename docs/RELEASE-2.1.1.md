# DOSY Lab 2.1.1 release notes

- Press **M** to edit an integral, **D** to split an integral, or **R** to delete the active integral in the main window. The toolbar shows the shortcuts. Text fields still accept these letters.
- In **Phase correction**, turn on **Set pivot** beside **Zoom range** and **Pan spectrum**. Click the spectrum, drag the pivot guide, or enter a value in ppm. Turn the mode off to resume phase adjustments.
- Closing the main window offers **Save project and exit**, **Exit without saving**, and **Cancel**. The save option closes the application after a successful write.
