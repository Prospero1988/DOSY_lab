# DOSY Lab 2.1.4 release notes

- Blocking processing errors appear in a red banner above the spectrum. A baseline mask that intersects an integral is reported with the two ppm ranges.
- The amber baseline warning names integrals outside the fitted range when baseline subtraction is applied. Check the yellow curve with **Show fitted baseline**.
- **QC** uses **INFO** for measurement diagnostics and **WARNING** for fit issues. The detailed shape, phase and baseline checks remain available for interpretation and ILT filtering. A dash marks an unavailable current result in the main table.
- Draggable dividers are marked with a 1 px line. Hover to highlight the divider and drag to resize the panels.
