# Experimental diffusion alignment for DOSY maps

Open **2D DOSY map** after completing the integrals and fits. Use **Map mode** to compare the following views. **Original DOSY map** is the default and keeps each reference spectrum segment at its own monoexponential D.

- **D-aligned DOSY · display only** moves the existing reference segments onto candidate group D values. Within an accepted group, the representative is the inverse-variance weighted mean when all SE(D) values are finite and positive, otherwise the median. Peak positions in ppm, spectral profiles and intensities are retained.
- **Global fit DOSY** fits one positive D across all included ROI decays of each candidate group. Each ROI has an independent amplitude. Check the group tree for original and shared D, and hover over each ROI for independent and shared residual RMS. An incompatible group keeps its independent D values. Clear a member checkbox to remove it from the fit and regroup the remaining ROIs. The group checkbox controls only map visibility.
- **Global ILT DOSY · ROI profiles** becomes available once a Global ILT calculation converges for the same processing and selected ROIs. Run it explicitly from the results table, then select the map mode. For a single retained component, the map places the reference profile at its ILT D. For multiple components, it estimates separate profiles from the measured spectra across the active gradient layers. This mode can preserve multiple components at overlapping ppm inside one ROI. Other ROI regions keep their original representation.

Adjust **D tolerance** with the slider or the exact numeric field. The range is 1–20% and starts at 5%. **Recalculate alignment** reapplies the settings. **Reset to original** switches to the original map and restores the full view. The controls for zoom, pan, guides, grid, floor, gain, band width and fullscreen work in all modes. PNG exports identify the active method and indicate how many ROIs were processed in a non-original mode.

## Clustering and shared fit

Grouping considers fits with positive finite D, at least five active points, R² between 0.95 and 1, and SE(D) at most 25% of D when a finite SE is available. These thresholds screen candidates for alignment. In increasing D order, a candidate joins the current cluster only if its symmetric distance from the smallest D in that cluster is within tolerance. The distance is `200 × |D₁−D₂| / (D₁+D₂)` percent. This bounds the distance between every pair of members and prevents chain linking. Singleton ROIs retain their own D.

The shared fit uses the original b, signed integrals and fit masks. Each column is divided by its largest absolute active integral. When the monoexponential fit used integral SE, the shared fit preserves its relative inverse-SE weights. Residual weights have unit L2 norm per ROI. At a trial D, each nonnegative amplitude is determined analytically, with its reference at the lowest active b. A bounded scalar minimization fits the shared D. A candidate is rejected if any ROI's normalized residual RMS exceeds both `1.5 × RMS independent` and `RMS independent + 0.005`. This is a screening heuristic. Tighter tolerance or manual membership can help isolate incompatible decays. Similar D or lower noise in a shared fit cannot establish molecular identity.

## ILT component profiles

Each candidate component uses the decay basis implied by its entire Global ILT interval, normalized at the displayed reference layer. Components below 5% of the ROI's predicted reference intensity are omitted. Edge peaks, poor integrated fits, too few active layers, ill-conditioned bases, large spectral reconstruction residuals and inconsistent reconstructed amplitudes trigger fallback to the original ROI. For each accepted multicomponent ROI, nonnegative least squares fits the fixed bases to the signed spectrum at each ppm bin. The check requires a normalized spectral reconstruction error of at most 15%, basis condition number at most 100 and agreement within 20 percentage points between the reconstructed and ILT reference shares. These are exploratory gates. They are sensitive to phasing, baseline, S/N and gradient coverage.

The method only operates inside selected ROIs. Points shared by overlapping ROI definitions remain masked in the display. The Gaussian width along D remains a display setting. The main fit table, source spectra and saved projects retain their original measurements and fit results.
