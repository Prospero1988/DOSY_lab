# DOSY Lab 2.1.3 release notes

- **Processing → Show baseline regions** controls the blue shaded areas on the spectrum. The setting is remembered across sessions. The selected regions still define the fitted baseline when their shading is hidden.
- **Select baseline** and **Clear baseline** are now in **Processing**. The yellow fitted baseline preview and the orange presaturation guides retain their own controls.
